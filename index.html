oyzmo Flatpak

Apps by oyzmo, with updates through GNOME Software.

Bindle

A small GNOME Markdown editor. Install Bindle (opens in GNOME Software), or:

flatpak install https://flatpak.oyzmo.no/bindle.flatpakref

Source code: github.com/oyzmo/bindle

wdill

A tiny 3D print file viewer: STL, 3MF, OBJ, STEP, GLB and FBX. Install wdill (opens in GNOME Software), or:

flatpak install https://flatpak.oyzmo.no/wdill.flatpakref

Source code: github.com/oyzmo/wdill

rmMeta

Removes hidden metadata from photos and documents before you share them. Install rmMeta (opens in GNOME Software), or:

flatpak install https://flatpak.oyzmo.no/rmmeta.flatpakref

Source code: github.com/oyzmo/rmMeta
